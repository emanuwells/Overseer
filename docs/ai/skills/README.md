# Competências locais

O repositório mantém apenas competências diretamente aplicáveis ao seu ciclo de manutenção:

- `repo-hygiene`: auditoria e remoção segura;
- `professional-documentation`: documentação técnica clara;
- `quality-gate-runner`: validação proporcional ao risco;
- `stop-the-slop`: revisão de texto vago ou enganador.

Estas instruções complementam `AGENTS.md`; não substituem o código, os testes nem as políticas de segurança.
