# Contribuição

Este projeto é orientado a desenvolvimento solo com apoio de IA. Ainda assim, todas as alterações devem seguir padrões de equipa sénior.

O fluxo público está em [`CONTRIBUTING.md`](../../CONTRIBUTING.md). Em ambiente local com toolkit WELLS, o contrato do agente está em `.agents/AGENTS.md`.

## Fluxo

1. Ler `CONTRIBUTING.md` na raiz (e `.agents/AGENTS.md` se existir).
2. Confirmar contexto em `PROJECT_CONTEXT.md`.
3. Trabalhar em branch dedicada para alterações relevantes.
4. Fazer alterações pequenas e reversíveis.
5. Executar validações definidas em `COMMANDS.md`.
6. Atualizar documentação e changelog quando aplicável.
7. Rever o diff antes de concluir.

## Critérios

- Código simples, legível e testável.
- Sem segredos.
- Sem ruído no repositório.
- Sem dependências desnecessárias.
- Sem refactors escondidos dentro de features.
- Documentação em PT-PT com acentuação correta.
