# Segredos

Esta pasta contém apenas documentação e exemplos seguros. Segredos reais ficam fora do Git.

## Regras

- Usar valores fictícios em exemplos.
- Não copiar tokens, passwords, cookies, certificados ou chaves privadas reais.
- Preferir variáveis de ambiente ou gestor de segredos.
- Manter ficheiros locais com credenciais reais ignorados pelo Git.

## Exemplos

- `examples/credentials.example.json`: formato genérico para credenciais fictícias.
- `examples/ssh-config.example`: exemplo de configuração SSH sem chaves reais.
